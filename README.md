# Temperature Converter 🌡️

A simple and user-friendly Temperature Converter Android application developed using Kotlin and XML in Android Studio[cite: 1].

## ✨ Features

- Enter temperature in Celsius (°C) or Fahrenheit (°F)[cite: 1]
- Bi-directional real-time conversion as you type[cite: 1]
- Supports decimal values and negative numbers
- Displays formatted temperature output
- Simple and clean user interface[cite: 1]
- Input validation for empty or invalid values
- Clear button to reset all input fields

## 🛠️ Technologies Used

- Kotlin[cite: 1]
- XML[cite: 1]
- Android Studio[cite: 1]
- Android SDK

## 🧮 Conversion Formulas

Temperature conversions are calculated using the formulas:

- **Celsius to Fahrenheit:** $°F = (C \times 9/5) + 32$
- **Fahrenheit to Celsius:** $°C = (F - 32) \times 5/9$

## 📱 How to Use

1. Enter a value in the **Celsius** or **Fahrenheit** input field[cite: 1].
2. The converted value instantly displays in the opposite field[cite: 1].
3. Click the **Clear All** button to reset the inputs.
